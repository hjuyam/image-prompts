第一种：从文字生成写真

当你没有现成照片，想先探索一个场景或摄影风格时，从风格库选一条提示词。提示词已经写好人物动作、环境、光线和镜头语言，可以直接作为创作起点。

  1. 打开风格库，按人物、场景或景别筛选，也可以搜索“咖啡馆”“逆光”“胶片”等关键词。
  2. 展开卡片，先看画面描述是否符合你的想法，再点击“复制”。
  3. 在你使用的图片生成工具中粘贴文字。把人物、衣服和地点改成自己的需求，再生成图片。
  4. 如果结果不理想，每次只调整一两个要素，例如先改光线方向，再改背景或镜头距离。

先改变量，再改风格词。“窗光从左侧照入”“人物转头看向窗外”通常比单独增加“高级感”“电影感”更能控制画面。

第二种：上传原图，修改照片

如果要把自己的照片改成某种写真场景，先上传原图，再使用支持图片编辑的模型。上传原图是让模型参考人物和构图的关键步骤；只粘贴场景提示词，往往会生成一个新人物。

  1. 在图片编辑工具中上传你有权使用的照片。
  2. 到修图模板选择“自然精修”“重新打光”“换背景”等操作，或从风格库复制想要的场景。
  3. 写明只修改什么，再逐项写明必须保留什么：人物身份、五官、表情、发型、服装或原有构图。
  4. 先完成一个修改，再检查脸、手、衣服边缘和背景光线。多轮编辑开始失真时，回到原图重新操作。

例如要把一张室内照片改成咖啡馆窗边写真，可以在场景描述前补上：

请以我上传的照片为基础，仅将背景与光线改为暖色咖啡馆的窗边场景。保留人物身份、五官、表情、发型、姿势和身体比例；让人物身上的光线方向与新背景一致。

这段文字提供的是编辑方向，不保证每个模型都能像素级保留原图。人物相似度要求高时，检查每次生成结果，必要时缩小改动范围。

一条好用的提示词包含什么？

可以按“人物和动作 → 场景 → 光线 → 镜头与构图 → 必须保留的部分”来组织。前四项决定要拍出什么，最后一项用于修改已有照片。

  • 人物与动作：让人物做一件具体的事，例如递出草莓、端着茶杯或回头看向镜头。
  • 场景：写清楚在哪里，并给出一两件可见的物品；“木质窗框与打开的杂志”比“温馨室内”更具体。
  • 光线：说明从哪里来、软硬如何、阴影落在哪里。真实感常来自一致的光照方向。
  • 构图：需要半身、全身、特写或横幅时直接说明。还可以补充 4:5、1:1 等画幅比例。
  • 保留项：编辑照片时把脸、发型、姿态及不需修改的背景分别点名。

不同工具对文字的理解和图片编辑能力会变化。库中的平台差异说明可以当作参考，最终以你当前使用的模型和实际出图为准。

常见问题

提示词可以直接复制吗？

可以。生成新图时直接复制；修改自己的照片时，先上传原图，再加上“仅修改什么、保留什么”的要求。

为什么画面有了，但人物不像原图？

检查是否上传了原图、是否写明保留身份和面部特征，以及是否一次更改了太多内容。先尝试只换背景或只改光线，再逐步增加变化。

为什么搜索结果和想象的不一样？

抽象词容易让模型自行补全。把“复古”“氛围感”拆成能看见的细节，例如低角度夕阳、轻微胶片颗粒、衣料纹理和人物动作。
